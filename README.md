# Delivery Management Demo

A **standalone frontend portfolio project** using fictional delivery records. This is not copied from or connected to any real client's logistics system.

## Features
- Add fictional delivery records with recipient, driver, and destination
- Search by reference, recipient, or destination
- Update status: Pending, In Transit, Delivered
- View dashboard counts by status
- Restore sample delivery records
- Store records locally in the browser using `localStorage`

## Technologies
HTML5, CSS3, vanilla JavaScript, DOM manipulation, and browser `localStorage`.

## Run locally
Open `index.html` in a web browser. No backend or credentials are required.

## Live demo
After enabling GitHub Pages, add your live URL here.

## Screenshots
Add screenshots of the fictional dashboard and delivery form in a `screenshots/` folder.

## Limitations
This demo does **not** implement GPS tracking, photo uploads, signatures, customer authentication, cloud storage, or an API. Its data is local to the browser and can be cleared.

## Privacy
No client names, real delivery records, private URLs, or credentials are included. Use fictional details only.
